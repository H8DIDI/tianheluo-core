# 排管竖向避让插件 · 设计方案（参考 Thermist Add-in）

## 1. 从 Thermist 学到的做法
（只看了安装包里的文件清单、功能区截图和界面文字，没有在模型里运行它的工具）

| Thermist 的做法 | 对我们的意义 |
|---|---|
| 一个功能区面板里放一组**小工具**：A to B、Jog、Wye、Coil Connect、Equipment Builder、Settings，每个工具只做一件事 | 我们也拆成几个单一用途的工具，而不是一个"全自动"大按钮 |
| **点选对象 → 点位置 → 先预览 → 确认**；"Click on route to add a node"，Esc 取消 | 排管工具同样：选范围 → 看结果表 → 确认写入 |
| Jog：点一根管，"绕过最近的碰撞，从上面或下面走" | 我们的"单根避让"：点一根排管，自动绕过最近的碰撞，上或下 |
| 写入是**一个撤销步骤**（"One undo step removes it all"） | 我们已用 TransactionGroup，一次 Ctrl+Z |
| Settings 窗口，参数**记住上次的选择** | 参数存 `Documents\KaifaTools\管综排管路由规则.json`，窗口读写它 |
| 求解失败、被取消都在日志里说明原因，Revit 回滚时给出原因 | 我们写入失败逐根列原因（已有） |

## 3. 参数（设置窗口，全部可改、可记住）
- 路面覆土 1.2 m；路外覆土 0.7 m
- 交叉净距 0.2 m；平行净距 0.05 m；夹角大于 30° 算交叉
- 最大坡度 8 %
- 底标高下限 0 m；**最深埋深：地面下 5 m**
- **两端标高取整：0.1 m**（0 = 不取整）
- 平面蹭井容差 0.30 m；井压井范围 5 m
- 路面楼板类型关键字（默认"道路"）；路外地面标高（空 = 取最近路面）
- 水管是否当障碍（默认否）
- 每轮求解时限、轮数

## 4. 流程与安全
1. 选范围 → 2. 读取模型（只读）→ 3. 求解在**独立进程**（Revit 不卡、不崩）→ 4. 结果表（原/新标高、变化、状态）→ 5. 确认 → 6. 写入前备份、一个撤销步骤、弹窗自动处理 → 7. 读回核对 → 8. 随时"还原上一次"。
- 不动平面、不动井；框外的排管只作障碍，不改。
- 被尺寸标注挡住的排管：写入失败后给出"删标注并重写"按钮，**删之前备份标注信息**，且必须你点确认。

## 5. 路线图
1. 单根避让做成"点选"（PickObject），用现有求解器，只放开这一根
2. 井处断开工具（含断开处标高一致）
3. 标高取整、接头对齐、碰撞检查拆成独立工具，功能区一个面板放全
4. 求解提速（分区并行、热启动）
5. 平面改线、并线（需要你确认规则后再做）

## 6. 最终目标：通用的“管道路由一键优化”（排管只是第一类对象）
目标不变：**一键**，对象不限于排管，也包括水管、风管、桥架、线管；规则放配置，换项目不改代码。

### 6.1 架构：求解核心与对象适配器分开
- **求解核心（类别无关）**：只认“带两端标高、截面尺寸、净距要求的直线构件”+“障碍物（井、沟、梁、板、其他构件）”，输出每个构件两端的新标高。现在的 CP-SAT 模型就是这个核心：每个障碍“上/下/违规”三选一、凸包线性化、接头联立、覆土/埋深/坡度/取整。
- **对象适配器（每类一个）**：负责从 Revit 读出构件、写回 Revit。
  | 类别 | 读取 | 写回 | 难点 |
  |---|---|---|---|
  | 排管（结构框架） | 起/终点标高偏移 | 改两个偏移参数 | 已做 |
  | 桥架 / 线管 | LocationCurve + 连接件 | 先在碰撞点打断（复制 + 改端点），再改标高，再用弯头连接两端 | Revit 没有桥架的原生打断 |
  | 水管 / 风管 | 同上 | `PlumbingUtils.BreakCurve` / `MechanicalUtils.BreakCurve` 打断，平移中间段，`NewElbowFitting` 连接 | 弯头角度、管件族是否存在、系统连续性 |
- **规则库 JSON**：每个“类别 + 系统关键字”一条：优先级、可否翻弯、净距、偏好标高带（例如“强电桥架距梁底 450”）。换项目只改这个文件。
- **一键 = 默认预设 + 范围**：预设里已经有全套参数，用户只选范围；高级用户再展开设置改参数。

### 6.2 分阶段做
1. **阶段 1（已基本具备）排管**：只改两端标高，不动平面。
2. **阶段 2 桥架 / 线管**：在碰撞处打断、翻弯，弯头自动生成；需要先验证弯头族。
3. **阶段 3 水管 / 风管**：打断 + 弯头 + 保温层 + 系统连续性。
4. **阶段 4 平面改线**：在竖向解不开时才启用（走廊、并线），用 NetTopologySuite 做平面障碍外扩和走廊。

### 6.3 为什么这样排
- 排管是“端点标高独立、没有弯头”的最简单情形，先把求解核心、预览、写回、还原、弹窗保护全部做扎实。
- 其余类别复用同一个核心，只新增读写适配器，风险集中在“打断和弯头”这一处，单独验证。
- 所有类别共用同一套“选范围 → 预览 → 确认 → 一个撤销步骤 → 可还原”的流程。
